# 複数文書の切り替え・保存・復旧

🟢 [Done] 新規作成、プロジェクトの読み込み、フォントライブラリからの読み込み、復旧を別の文書タブへ接続する。既存の未保存文書を置き換えない。最大16文書を同時に保持し、保存済みタブにはファイル名、未保存タブには書体名と文書番号を表示する。全文書の正本はRust側にある。

## 操作と状態

タブのクリック、またはフォーカスしたタブで左右キー／Home／Endを使って切り替える。横幅を超えるタブはスクロールでき、選択したタブを表示範囲へ移す。＋は新規文書、×はその文書を閉じる。標準メニューの「文書を閉じる」と⌘Wにも対応する。フローティングパネルやライブラリにフォーカスした場合の⌘Wは、そのウインドウを閉じる。

文書ごとにEditor、Undo/Redo、選択グリフ・ノード、ズーム・パン、ツール、表示設定、試し組み、画像・スニペットの編集状態、保存先・保存済みrevisionを保持する。文書の切り替えでUndo/Redo履歴を初期化しない。パネル配置・フローティング座標・UI言語・キャンバスの現在サイズは共通のワークスペース設定であり、文書を切り替えても維持する。分離パネルとGPU描画も選択中の文書を表示する。

未確定のペン入力やドラッグがある間の切り替え・新規読み込みは拒否し、確定または取消を促す。保存ダイアログや復旧処理中の切り替えも直列化する。切り替えるたびにepochを更新して、古いウインドウ・非同期処理から届いた編集命令が別文書へ適用されることを防ぐ。文書データや画像フレームをWebViewへ転送しない。

操作ラベル、エラー、未保存確認は英語・日本語・简体中文で提供する。

## 保存・閉じる・終了

保存／別名保存は選択中の文書だけを対象とする。同じプロジェクトを再び開くと既存のタブへ切り替え、読み込み直しによって未保存編集を失わない。別の開いている文書が使う保存先への書き込みは拒否する。パスの比較は可能な場合にcanonicalizeして行う。

未保存の文書を閉じると、対象の書体名と文書番号または保存先を添えた「破棄／キャンセル」の確認を表示する。保存する場合はキャンセルして、その文書を選択し保存する。取消時は文書と復旧用コピーを保持する。破棄時はその文書のコピーだけを整理し、他の文書へ影響しない。確認中に文書revisionが変わった場合も閉じずに競合として扱う。最後の文書を閉じた場合は、履歴のない空文書を開く。

アプリ終了時は非表示の文書を含めて未保存変更を列挙し、キャンセルで全て保持する。起動直後の未編集サンプルと、最後の文書を閉じた後の空文書には不要な確認を出さない。正常終了で破棄を承認した現在セッションの復旧用コピーは整理する。未消費の過去セッションの候補は保持する。

## 文書単位の復旧

非表示の文書も含め、未保存文書それぞれに独立したチェックポイントとロックを作る。約3秒静止後、連続編集中は約30秒ごとに保存を試みる。元の保存ファイルを上書きしない。保存済みになった文書のコピーだけを整理する。

異常終了後は各文書が独立した候補として表示される。復旧は未保存の新規タブとして開き、既存タブを残す。新しいコピーを書き込めてから該当する元候補だけを消費する。復旧失敗や16文書の上限到達時は元候補を残す。別の候補の復旧・破棄や現在の文書保存で、他の候補を消さない。

復旧するのは最後のチェックポイントの文書内容で、Undo/Redo履歴や未確定操作は復旧しない。通常終了後の文書タブ一覧の自動再オープンは対象外であり、保存済みファイルは「開く」から再度開く。保存形式の互換性と復旧候補の旧形式は維持する。詳細は[自動保存・異常終了後の復旧](autosave-recovery.md)。

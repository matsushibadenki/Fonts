# ペン・パス加工（2026-11-04）

## 操作

- クリックで角の点、ドラッグで対称ハンドルを持つ点を追加。隣接する点にハンドルがあれば三次ベジェ、両方ハンドルなしなら直線になる。Shiftは追加点の方向・ハンドル方向を45度に制限する。
- 3点以上の始点クリック、Enter、閉鎖アイコンで閉じて確定。Shift+Enter／チェックで2点以上の開輪郭を確定。Backspace／Delete／戻るアイコンで最後の仮点を削除。Escで仮描画全体を破棄。ポインターキャンセル・ウインドウのフォーカス喪失は現在追加中の点だけを破棄する。
- 輪郭パネルの加工行から方向反転、開閉切り替え、選択区間の直線化。区間は従来の中間点追加と同じく選択点の手前、始点選択時は最初の区間。方向反転は塗りの穴に影響し得る。開閉切り替えは既存セグメントを削除しない。閉じたパスを開くと終点が始点と同じ位置に残る場合がある。
- 開輪郭は編集・保存できるが、フォント出力前には閉じる必要がある。線・曲線の二重点をダブルクリックで誤って確定しないよう、旧ダブルクリック確定を明示的なEnter／アイコンへ置き換えた。

## 所有・履歴・保存

アンカー、ハンドル、仮描画はRust Modelが所有する。WebViewはポインター命令と件数を送受信する。描画は既存wgpuの輪郭・ハンドル経路。1輪郭の確定、方向反転、開閉、直線化それぞれが1回のUndo。Redo、既存のプロジェクトJSON、文書単位保存・復旧に同じContourを使用し、スキーマの変更を伴わない。未確定の仮描画は保存データに含めず、従来の編集中保護を維持する。

ペンは4096点まで。非有限値・座標範囲外を拒否。加工はコピーを検証してからrevision付きEditorへ適用し、不正な区間・古いrevisionでは文書を変更しない。反転は二次制御点を保持し、三次制御点の順序を交換。閉輪郭の始点、暗黙の閉鎖辺、滑らか点の添字も対応させる。

## 開輪郭の継続・連結と非対称ハンドル（2026-11-04）

### 操作

輪郭パネルで開輪郭の始点または終点を選択し、継続アイコンでペンへ切り替える。反対向きから描く場合も元の二次・三次曲線をそのまま逆順に保持する。新しい点を描いた後、チェック／Shift+Enterで開いたまま確定、閉鎖アイコン／Enter／継続元の反対端クリックで閉鎖する。Backspaceで追加点を順に戻し、最初の継続点からのBackspaceかEscで取り消す。

連結は、同じ行のリストで接続先の輪郭番号と始点／終点を選び、連結アイコン。選んだ端点同士を直線で結ぶ。端点が完全に一致すれば余分な線を追加せず結合する。向きは必要に応じて反転し、元の制御点と内部の滑らか設定を保持する。同じ輪郭の反対端を選ぶと閉鎖。閉輪郭や中間点は接続対象にできない。初期選択は別の輪郭を優先する。

ノードツールでOption／Altを押しながら制御点をドラッグすると、その接続点の連動だけを解除して片側を移動する。反対側の位置・長さは保つ。独立ハンドルのアイコンは、選択した滑らか点の両ハンドルを動かさず連動だけ解除する。通常のドラッグは既存の滑らか連動を維持。ペンでは通常ドラッグで両側、Option／Altを押した後のドラッグで出側だけを編集する。入側はAlt開始時点の位置を保持し、Altを最初から押すと入側は端点上に残る。独立操作はポインターを離すまで保持する。

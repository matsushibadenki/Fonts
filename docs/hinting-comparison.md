# ヒンティングの小サイズ比較

フォントライブラリで静的・単色のTrueType／CFF1（CID-CFF・単体CFFを含む）を選び、ヒンティングのアイコンを開く。サンプル欄の隣にある目のアイコンで「元のヒント」「ヒントなし」「自動生成」を並べて確認できる。書き出しモードとは独立して比較し、元ファイルと制作中の文書は変更しない。

- 9／12／16／24ppem、同じ文字列・基準線・グレースケールで比較する。
- 最大12 Unicodeスカラー値。未収録の文字数を表示し、該当箇所はフォントの.notdefとして描画する。整形・合字・カーニングは適用しない。
- 1×は画像1画素を論理1ピクセルで表示、2×は補間なしで拡大する。高DPI画面の物理画素とは一致しない。横・縦スクロールで全体を確認できる。
- 自動生成だけが失敗した場合は、その理由と元のヒント／ヒントなしの2列を表示する。サンプル変更時は古い結果を消し、目のアイコンまたは入力欄のEnterから再生成する。
- 表示枠は各320×64px。長い送り幅、負のサイドベアリング、極端に高い字形は切れる場合がある。

`font-core::hinting_preview` が既存の保持／除去／自動生成を使い、FreeTypeの `NO_AUTOHINT | NO_BITMAP` で実際のヒントを実行する。ヒントなし列ではさらに `NO_HINTING` を指定する。OSのCoreText／DirectWriteの再現ではなく、同じラスタライザーでの比較である。

Tauriのworkerでフォントを処理し、Rustのアプリ状態へ最新1回分・最大12枚のPNGを保持する。IPCは世代番号・サイズ・文字列・結果のみ。`hintpreview:` の画像リソースは生成元ウインドウと世代を検証し、古い結果・別ウインドウ・任意パスの参照を拒否する。制作画面のwgpu描画やDocumentには手を加えない。新しい外部ライブラリは追加しない。

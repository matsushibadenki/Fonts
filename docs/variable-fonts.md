# 可変フォントと静的インスタンス

フォントライブラリで可変フォントを一つ選択し、「可変フォント」アイコンを開く。英語・日本語・简体中文に対応。各軸の名前・タグ・範囲・既定値を読み取り、スライダー／数値入力で値を設定できる。リセットは全軸を既定値に戻す。非表示軸も◇付きで操作できる。未知の軸、範囲外、非有限値はRust側でも拒否する。

「プレビュー」は入力テキストをメインのwgpu試し組み画面に表示する。軸を変更した後はもう一度プレビューを押す。既存文書の輪郭やUndo履歴は変更しない。試し組み画面にも書体名と軸値を表示する。試し組みのテキスト・サイズも変更できる。「描画」へ戻ると通常文書に戻る。外部プレビューのグリフクリックによる文書選択は無効。処理中に文書や試し組みの世代が変わった結果は適用しない。

「静的インスタンスを開く」は独立した新規文書として追加する。既存の文書別Undo/Redo・保存・自動保存・復旧を利用できる。開いた文書は通常の静的輪郭データであり、元の可変フォントや軸の編集状態を埋め込まない。

「静的インスタンスを出力」はTTF・OTF（CFF）・WOFF2に対応する。ネイティブ保存ダイアログ、キャンセル、拡張子・保護ディレクトリーのチェック、原子的保存を共通処理で行う。出力を再解析して静的であること、グリフ数、Unicode対応、字幅、輪郭の有無を確認し、保存したバイト列を読み戻して一致を検証する。WOFF2はさらに復号する。検証完了後に保存先とサイズを表示する。

変換はRustのttf-parserによってgvar（複合輪郭を含む）／CFF2、avar、HVAR、MVARを評価し、編集用モデルから静的フォントを再構築する。大容量の元フォント・輪郭はRust側に保持し、WebViewとの通信は軸メタデータ・数値・テキスト・処理結果のみ。現行エンジンの上限は63軸。

元ファイルをそのまま固定化するロスレス処理ではない。元のGSUB/GPOS、可変カーニング、カラー、hinting、縦組み情報は保持しない。静的な字幅・輪郭・横組みascender/descenderと主要スタイル属性を展開する。元フォントのライセンス／著作権表記は取り込み、利用条件は元フォントに従う。可変フォント自体の編集・出力、軸状態のプロジェクト保存は将来項目。

テスト用フォントは独自の幾何学輪郭からFontToolsで生成したMIT素材。gvarとCFF2、wght/wdthの複数軸、非線形avar、HVAR/MVAR、範囲検証、静的3形式の再解析、破損・可変出力の拒否を自動検証する。生成用Python/FontToolsは開発用であり、アプリの実行には不要。

## 名前付きインスタンス（2026-10-19）

可変フォントの設定画面上部でRegular／Bold等の登録済みインスタンスを選ぶと、非表示軸を含む全軸をまとめて設定する。日本語・简体中文の登録名があれば表示言語に合わせ、なければ英語名を表示する。登録がない書体にも既定インスタンスを用意する。軸を手動変更すると「カスタム軸」に切り替わり、リセットは既定インスタンスへ戻る。

名前付き設定のままプレビュー／独立文書として開く／静的TTF・OTF・WOFF2へ出力できる。静的文書のスタイル名は元の英語名を使い、保存・再読込でも保持する。元のPostScript名をそのまま流用する機能ではなく、既存の静的出力処理で名前を構築する。カスタム軸は従来のタグ・数値によるスタイル名を使う。

Rustでfvarのレコード長・件数・範囲・予約フラグ・軸値を検査する。Optional PostScript name ID付き／なしの両レコードを扱い、同じ座標の重複は最初の設定を使う。最大4,096登録、表示名は256 Unicodeスカラー値に制限する。選択IDと全軸値の一致を処理直前にも検証し、改変・不整合を拒否する。座標はユーザー値で渡し、avarは既存の静的化処理で一度だけ適用する。仕様根拠：[OpenType fvar](https://learn.microsoft.com/en-us/typography/opentype/spec/fvar)。

独自作成のgvar／CFF2テスト書体に名前付き設定と三言語名を追加。名前の切替、全軸値、スタイル名・主要属性、静的3形式、JSON文書、既定補完・重複・Optional項目・不正レコードと不整合拒否を自動検証する。実行時Pythonや追加の外部依存は不要。

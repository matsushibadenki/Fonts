# パネルの入れ子split

🟢 [Done] 左・右・下の各ドックで、タブ群を上下または左右に分割し、さらに各領域を入れ子で分割できる。4種類のパネルはそれぞれ1つの配置先を持ち、複数のウインドウはRustのWorkspaceを表示する。フォント文書やGPUデータをWebViewへ複製しない。

## 操作

各パネル見出しの分割アイコンから配置先を選び、左・右・上・下のアイコンで分割する。タブアイコンでは配置先と同じタブ群にまとめる。見出しをドラッグすると、パネル内の端に分割先、中央にタブ結合先が表示される。画面端のドックアイコンへ移動する既存操作も維持する。

各分割の境界はドラッグまたは矢印キーで変更する。比率は15〜85%。狭い領域ではスクロールでき、操作部が消失しない。左右分割時にはサイドドックを最低320pxへ、下ドックの上下分割時には高さを最低300pxへ広げる。ドック外側の境界も従来どおり調整でき、下ドックの高さは100〜520px。

操作ラベル・ツールチップ・情報アイコンの説明を英語、日本語、简体中文で提供する。

## 保存とフローティング

`workspace.json`の`trees`に各ドックの二分木を保存する。葉は順序付きパネル一覧とアクティブタブ、分岐は方向と比率を保持する。旧設定に`trees`がない場合は、既存のドック配置とアクティブタブから移行する。リセットは分割も初期化する。レイアウトはフォント文書のUndo/Redoとは独立した設定。

分離したパネルの位置は、ツリー内に非表示の配置枠として保持する。ほかに表示するパネルがない枝は画面上で折りたたむが、保存した比率は変更しない。分離ウインドウを閉じる、または元のドックへ戻すと、その位置を再利用する。分離ウインドウの分割アイコンから別のパネル脇へ直接配置することもできる。別のドックへ移動・タブ結合した場合は元の空枝を整理する。再起動時はツリー・タブ・比率・分離状態とウインドウ座標を一緒に復元する。

Rust側でrevision、パネルの重複・欠落、所有ドック、木の深さ、比率、操作先を検証する。不正な移動は変更を確定せず、古いウインドウ状態からの操作は競合として扱う。ツリーの分割数は4パネルにより最大3分岐に制限される。

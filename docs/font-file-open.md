# フォントファイルを文書として開く

🟢 [Done] メイン画面の読み込みアイコン、または「ファイル → フォントの全文字を読み込む…」からフォントファイルを選択する。選んだフォントの全グリフ（.notdef、Unicode未割当、Unicodeの別名を含む）を、新しい未保存文書へ読み込む。

🟢 [Done] 「ファイル → 開く…」（⌘O／Ctrl+O）はプロジェクトJSONとフォントの両方を選択できる。JSONは従来どおりプロジェクトとして復元し、それ以外はフォントの読み込み経路へ渡す。元フォントのパスをプロジェクトの保存先に登録しないため、「保存」は別のプロジェクト保存先を指定する。

対応する選択形式はTTF・OTF・TTC・OTC・WOFF2・PFA・PFB・CFF・CID。WOFF2はRustで展開してから読み込む。TTC／OTCに複数書体がある場合は、書体名・スタイル・グリフ数・フェイス番号を表示する選択ダイアログを開く。選択したフェイスの全グリフを1文書へ読み込む。上限は256フェイス、元ファイル256MiB、文書16件、輪郭量は既存読み込み制限に従う。

読み込みは既存の静的な輪郭編集モデルを使用する。可変フォントは既定の軸値、元の組版・ヒンティングは保持しない。カラーフォントはカラー情報を暗黙に落とさず、専用画面を案内して拒否する。新規文書には既存の読み込みと同じ「Edited」付きのファミリー名を使用する。Unicode未割当のグリフは文字一覧でグリフ名から選択できる。

解析と読み込みはRust workerで完了してから文書を追加する。失敗・キャンセル時に既存文書を置き換えない。文書別Undo/Redo、保存・復旧、タブの切り替え、編集中の操作の保護、未保存の閉じる確認は既存機構を使う。ファイル処理はFileGuardで直列化し、コレクションの元データはRustだけに保持する。WebViewには書体名・件数と識別子のみを渡す。キャンセル時は元データを解放し、古い識別子や別ウインドウからの選択を拒否する。

三言語（英語・日本語・简体中文）のメニュー、読み込みボタン、ヘルプ、書体選択、読み込みエラーに対応する。

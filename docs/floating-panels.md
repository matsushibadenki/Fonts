# フローティングパネルの保存と復元

🟢 [Done] グリフ・メトリクス・輪郭・スニペットの各パネルについて、分離状態と最後の通常ウインドウの位置・サイズを復元する。設定はRust所有のWorkspaceとしてアプリ設定ディレクトリの`workspace.json`へ保存し、フォント文書の保存やUndo/Redoとは独立している。

移動・リサイズ・DPI変更のイベントから300ms静止後に保存し、500ms周期でモニター構成の変更を確認する。ドッキング直前と正常終了時にも最新の座標を取得する。閉じる操作は従来どおりドックへ戻し、次に分離した際には前回の座標を使う。アプリ終了時に分離していたパネルは、再起動時にも分離して開く。最小化・最大化・全画面の座標は通常サイズに上書きしない。

## モニター変更への対応

位置は物理座標、内側と外側のサイズは論理サイズ、モニターは名前・物理作業領域・倍率を保持する。同名モニターが複数ある場合は以前の領域との重なり・距離で選ぶ。モニターが移動した場合は作業領域からの論理距離を維持し、切断された場合は現在のウインドウと重なる画面、またはメインウインドウの画面へ戻す。

ウインドウ全体を単一モニターの作業領域内へ収める。画面間の隙間を表示可能領域として扱わない。通常は8論理pxの余白を設け、解像度が小さい場合は最小サイズも緩和して縮小する。OSの装飾サイズは復元時に再取得する。起動時は非表示の状態で位置・サイズを適用してから表示し、復元に失敗したパネルはドックへ戻す。失敗通知と操作説明は英語・日本語・简体中文に対応する。

## 互換性とリセット

`floating_bounds`は省略可能なフィールドで、旧設定の読み込みに対応する。不正な座標は該当パネルの座標だけを破棄し、言語やドック配置は保持する。従来の3パネル構成からスニペットを含む4パネル構成への移行も維持する。「レイアウトをリセット」は保存座標も消去する。

Software update / ソフトウェアアップデート / 软件更新

- Preferences → General → Software update: check, download, signature verification, install and restart.
- 環境設定 → 一般 → ソフトウェアアップデートから確認・ダウンロード・署名検証・インストール・再起動に対応。
- 偏好设置 → 常规 → 软件更新：检查、下载、签名验证、安装并重新启动。
- Save every document before installation. 未保存の文書がある場合はインストールを停止します。安装前请保存所有文档。

macOS Apple Silicon (arm64). Download the DMG or app archive, then move Fonts.app into Applications. This is the first updater-enabled release; older builds require this one-time manual installation.

# 実輪郭のグリフサムネイル

文字一覧はOSの代替フォントで文字を表示するのではなく、文書に保存された輪郭から字形を表示する。Unicodeがなくても、CIDグリフや異体字を形で選択できる。Unicode／CIDラベル、検索、選択、レビュー状態は従来どおり利用できる。

## データと描画

- Rust/wgpuで128×128pxのサムネイルを描画する。凹形状・穴は既存のeven-odd stencil塗りを使用し、開いた輪郭も線で表示する。エディタのガイド・制御点は表示しない。
- 負のサイドベアリングや高い結合文字が切れないよう、制御点を含む輪郭全体を余白付きで収める。各グリフを字形の外接範囲でフィットするため、一覧内の大きさはメトリクス比較には使用しない。
- WebViewは`thumbnail://localhost/{epoch}-{revision}-{id}.png`（WindowsではTauriの対応URL）を画像リソースとして読み込む。JavaScriptへの輪郭や生ピクセルのIPC転送、base64化、ブラウザでの輪郭処理は行わない。小さなPNGへのエンコードと画像リソース応答はRust側で完結する。
- 既存の256件ページ分割と画像のlazy loadingで、現在ページの表示周辺を優先する。文書はアプリのRust側だけが所有し、フローティングウインドウも同じサービスを利用する。
- アプリ所有の専用workerがGPU処理を直列化し、依頼キューは512件、PNGキャッシュはLRUで最大512件。キャッシュキーは文書epoch・revision・glyph ID。ページ往復で再利用し、編集・Undo/Redo・文書切替では古い世代を破棄する。
- 文書ロック中は世代・ID確認と輪郭のコピーのみ行い、GPU描画・PNGエンコード中はロックを保持しない。現在の文書と一致しない世代の依頼は拒否する。ブラウザキャッシュはno-store。

## 表示と制約

輪郭のない空白は`␣`、それ以外の輪郭なしは`◌`で表示する。描画できない輪郭やGPU初期化失敗では`⋯`を表示し、別フォントの文字で代用しない。説明は英語・日本語・简体中文のtooltipにまとめ、ボタンのアクセシブル名にはグリフ名・Unicode・CIDを保持する。

元の輪郭・advance・コードポイント・編集履歴・フォント出力は変更しない。複雑すぎる輪郭は既存の描画上限に従い、ひとつの失敗が他のグリフを停止しない。

## 検証

自動テストは負の座標・高い制御点のフィット、不正座標の拒否、リソースパスの厳密検証、LRU上限・世代切替を対象にする。実GPUの読み戻しテストは異なる実輪郭、穴の保持、余白、ガイドのない空白画像を確認する。

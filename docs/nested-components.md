# 部品の入れ子参照・循環参照検査（2026-11-06）

## 使い方

🟢 [Done] 参照部品を子として組み合わせ、親部品を登録できる。グリフに部品を参照配置し、配置の全輪郭と必要な通常輪郭を選んで、名前を付けて登録する。部品パネルの「選択輪郭」には全選択／解除を設けた。参照配置の一部だけを選ぶと、三言語で全輪郭が必要なことを示して拒否する。通常輪郭だけの登録と独立スニペットは従来どおり。

子の共有更新は全ての親・祖先・グリフ配置へ届く。同じ子を同じ親で複数回使う構成や、子を複数の親で共有する構成に対応する。生き残る点・制御点・輪郭のUUID対応を引き継ぎ、既存の配置行列は維持する。

親を選ぶと子部品の一覧を表示する。展開して位置・幅・高さ・角度を数値変更すると、親の定義とその利用先を更新する。狭いパネルでは入力欄を一列にして数値の欠けを防ぐ。子の参照解除は現在の輪郭とIDを親の中に固定し、その子の将来の更新から独立させる。削除は輪郭も取り除くが、親を空にする削除は許可しない。

子側からは直接参照している親へ移動できる。「影響する配置」は親を経由するグリフ配置も表示し、経由する親の名前を併記する。一覧の変形・参照解除は表示された配置全体を対象とし、親経由の場合は親の配置全体を扱う。直接の参照数にはグリフ配置と親の子リンクを数え、未配置の親から参照される部品の削除も保護する。

子の変形・解除は定義を変更し、編集元グリフを自動で書き換えない。「選択輪郭で定義を共有更新」はその時点の選択構成で定義を置き換えるため、編集元が古ければその構成へ戻る。編集元へ移動する際は、元になった配置IDから現存する全輪郭を探し、子の分割・追加後にも全体を選択する。元の配置が消えても定義・入れ子・配置先は保持する。

## Document・評価・保存

`Definition.children`に永続UUIDをキーとした子リンクを追加した。各リンクは定義UUID、変形行列、元ノードと親の中のノードのUUID対応、任意の編集元配置IDを持つ。編集元配置IDは補助情報であり、依存関係は定義UUIDで判定する。子が変わると子から親の順にキャッシュを再構成し、全グリフの配置を一括して更新する。

定義・子・グリフ配置はRustのDocumentが所有する。定義の輪郭は子の変換結果を含む検証済みキャッシュで、読み込み・保存・共有更新時に整合性を検査する。子の変形、欠落した定義、壊れたID対応、キャッシュの改ざんを拒否する。ID表と未変更の輪郭はArcで共有し、座標だけが変わる更新でID表を不要に複製しない。

評価は定義ごとに一度行い、子を展開する際に再帰的に全経路を繰り返し評価しない。配置先の輪郭は既存のwgpu描画・サムネイル・試し組み・TTF／OTF／WOFF2出力で使用する。UIに渡すのは一覧・ID・数値状態で、フレームはIPCへ転送しない。子の変形欄に必要な位置計算も選択中の親に限定する。

入れ子を導入したプロジェクトはv4を使用する。旧v1／v2／v3も読み込め、子を持たない既存v3の部品定義は空の子一覧として扱う。入れ子を全解除しても、通常の保存ではv4を維持する。初回導入のUndoでは導入前のschemaとデータを復元する。旧形式を開いただけで元ファイルを上書きしない。

親登録、共有更新、子の変形・解除・削除はそれぞれ1回のUndo/Redoへまとめる。全祖先・配置先・UUID対応・依存関係を一緒に戻す。定義・子・配置を埋め込み、保存・復旧後も参照を維持する。未確定プレビューやメモリ内Undo履歴を再起動時に再開する機能ではない。

## 循環・容量の制限

変更と読み込み時に依存グラフを検査する。自分自身への参照も、複数の定義を経由して戻る循環も拒否する。欠落参照も拒否し、検査に失敗した変更では文書・履歴を変更しない。

最下位の定義を含めて最大16段。グリフへの最終配置は段数に含めない。深さは共有された子の評価済み結果を再利用しても正しく数える。定義は256件、子リンクは全体4096件まで。展開後の各定義は128輪郭／16384点、定義全体65536点、全ID対応表1000000件までとし、子の展開が指数的に膨らむ構成を確定前に拒否する。グリフ配置・座標・保存容量には既存の上限も適用する。

一般アフィン行列はコアで保持できるが、数値UIで編集できるのは移動・非等方拡縮・回転で表現できる配置のみ。反転・シアーなどを黙って別の行列へ置き換えない。親の通常輪郭は[専用編集モード](component-definition-editing.md)でも直接加工できる。子輪郭は保護し、子定義を開くか参照を解除して編集する。

# Webフォント用WOFF2出力

🟢 [Done] 現在の文書を静的WOFF2として出力する。ファミリー名、TrueType／CFFの輪郭形式、Brotli圧縮の4段階（1・5・9・11）を設定できる。標準値はTrueType・9。設定・説明ツールチップ・検証結果を英語、日本語、简体中文で提供する。設定は出力ダイアログを閉じても同じ起動中は保持し、フォント文書の内容・保存済み状態・Undo/Redoは変更しない。

## 操作

出力アイコンから「Webフォント (.woff2)」を選び、輪郭形式と圧縮を設定して出力する。圧縮は容量と処理時間を変え、輪郭品質は変えない。TrueTypeでの三次曲線近似と、CFFでの三次曲線保持は既存の各出力処理に従う。

保存ダイアログは`.woff2`を初期ファイル名へ付ける。拡張子なしの指定は補完し、異なる拡張子や保護されたフォントディレクトリへの書き込みを拒否する。保存キャンセル時は設定画面へ戻り、成功表示を出さない。保存成功後は、検証完了・実際のパス・ファイルサイズを表示する。ライブラリの単体／一括変換から選ぶ場合は標準設定を使う。

## 形式と検証

[W3C WOFF2仕様](https://www.w3.org/TR/WOFF2/)に従う、単一SFNT・無変換テーブル＋BrotliのプロファイルをRustで生成する。`glyf`／`loca`はnull transformのバージョン3、それ以外は0。既知タグ、UIntBase128、ヘッダー、`head`のフラグbit 11とチェックサム、末尾の4バイト整列を処理する。生成元は既存の静的TrueTypeまたはCFF OTFエンコーダーで、DSIGは生成しない。

書き出し前にWOFF2を復号し、再構成した全テーブルが元の出力と一致することを確認する。保存後も実ファイルを読み戻し、生成バイト列との一致・ヘッダー・ディレクトリ・Brotliの展開長・SFNTとしての読み取りを検証する。一括変換でも読み戻し、不正な新規出力を残さない。検証失敗は成功扱いにせず、三言語でエラーを表示する。処理とフォントバイナリはRust側に置き、WebViewへ送るのは設定と結果だけ。

Unicode（補助平面を含む）、名前・メトリクス、作成した明示ペア・クラスカーニングのGPOSを保持する。アタリ画像は従来どおり出力しない。取り込み元の組版・ヒンティング・可変軸・カラーの完全なラウンドトリップ、WOFF2入力、コレクション、サブセット、WOFF2固有XMLメタデータは対象外。一般のWOFF2を読むインポーターではなく、内部検証用デコーダーはこの無変換プロファイルに限定する。

# 制御点の複数選択・一括加工（2026-11-05）

## 操作

🟢 [Done] ノードツールで端点・二次／三次曲線の制御点をShift＋クリックして追加・解除する。空白からドラッグすると矩形内の両方を選び、Shiftで既存選択へ追加する。Esc・フォーカス喪失・ポインター取消では矩形選択前の集合へ戻す。閉鎖点の重複を数えない。選択済み点の通常クリックは混在選択を保持する。

輪郭パネル上部に全アンカー／全制御点の選択アイコン、解除、件数、X／Y移動量、X／Y拡縮率（%）、回転角（度）を置く。説明は情報アイコンのツールチップへまとめ、英語・日本語・简体中文に対応する。キャンバスの⌘A／Ctrl+Aは全アンカー、⌘Shift+A／Ctrl+Shift+Aは全制御点を選ぶ。矢印キーは1フォント単位、Shift併用は10単位移動する。

選択点のドラッグ・数値移動は全選択点を同時に移動する。拡縮・回転は明示的に選択した点の外接矩形の中心を使い、X／Y拡縮後にフォント座標の反時計回りで回転する。負の率は反転、0はその軸を中心へ収束する。空入力・非有限数をUIで拒否し、Rustで座標範囲・点アドレス・revisionを再検証する。途中で失敗すると全体を変更しない。

## 幾何・履歴・描画

三次曲線の端点に付随する制御点も変換する。二次曲線の共有制御点は両端点を選んだ場合、またはその制御点を明示選択した場合に変換する。付随点を明示選択しても一度だけ変換し、加工は常に開始前の形状から計算する。対象外の点・輪郭を保持する。

単独ハンドルのドラッグは従来の滑らか連動を保持し、Option／Altで独立編集できる。複数点のドラッグと数値加工は指定点を優先し、接線が一致しなくなった接続箇所の滑らか制約だけ解除する。全体のアフィン変換で接線が維持される場合は制約を保持する。

RustのModelが選択集合とドラッグ中の原形・仮形状を所有する。wgpuは端点を青い四角、制御点を青い円で強調し、加工中の仮形状と矩形枠も描く。WebViewには選択アドレス・件数・状態を渡し、フレームデータをIPCへ流さない。

ドラッグの全移動を1回のUndoへまとめ、数値加工も1回のUndo/Redoで戻せる。点・輪郭UUIDを保持し、確定形状と滑らか属性を既存のプロジェクト保存・自動保存・復旧へ接続する。選択集合や操作途中の仮形状は一時状態として扱い、プロジェクトには保存しない。Undo/Redo・文字変更・構造変更・貼り付け等の既存の選択解除で端点と制御点をまとめて解除する。

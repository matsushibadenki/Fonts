# 可変フォントの専用文書

ライブラリの可変フォント画面から「可変フォントのコピーを編集」を選ぶ。元ファイルを変更せず、選択したフェイスと軸設定をプロジェクトv6へ格納する。保存・自動復旧後も元ファイルなしで再開できる。

## 実装済み

- 🟢 [Done] 元の範囲内で軸の最小値・既定値・最大値を編集する。プレビュー座標、名前付きインスタンスの選択、現在の既定値へのリセットに対応し、文書単位のUndo／Redo・保存・復旧へ接続する。
- 🟢 [Done] 同梱HarfBuzzでgvar／CFF2、avar、HVAR／MVAR、対応する組版の変動情報を変換する。最小値と最大値が等しい軸は固定し、全軸が固定されると静的出力になる。名前テーブルを全言語で保持し、既定値変更で無効になるfvarの既定専用name IDを修正する。
- 🟢 [Done] 元と同じTTF／OTF、および圧縮設定付きWOFF2へ出力する。保存ダイアログ、構造・全テーブルの照合、保存後の読み戻しへ接続する。WOFF2は外部シリアライザーのテーブル間の隙間・物理順序も正規化する。
- 🟢 [Done] プレビューはRust workerで選択座標を静的化してwgpuへ描画する。元フォント・輪郭・画素はRust側に保持し、IPCでは数値・テキスト・状態のみを渡す。古いepoch／revisionの結果は拒否する。
- 🟢 [Done] 「静的コピーを開く」で独立した文書を作る。対応するGSUB／GPOS・可変カーニング・IVS・縦組みを静的化して保持する。カラー可変フォントはCPAL編集と併用でき、静的コピーにもカラーを保持する。
- 🟢 [Done] 英語・日本語・简体中文の専用UI。プレビュー座標と出力の既定値は独立して扱い、元の名前付きインスタンスが編集後の範囲外なら選択を無効にする。

## 対応範囲

この文書は軸範囲・既定値・座標を編集する。通常の輪郭・メトリクス・フォント名・部品操作はロックし、グリフ一覧は元の既定輪郭を表示する。輪郭を加工する場合は静的コピーを開く。

🟢 [Done] TrueType／CFF2・合成グリフのマスター編集、全マスターでの点分割・削除、原点保持をv8へ接続。文書別のUndo/Redo・保存・復旧、可変出力・静的化に対応。[操作と保護条件](variable-masters.md)。

最大63軸、埋め込み元フォント128 MiB。軸の新設や元の範囲を超える拡張は行わない。JSTF・kerx・Graphite等、現在のOpenType変換器で安全に位置調整を変換できないエンジンは変換時に拒否する。通常のフォント読み込みでは、元の組版情報を除いて既定輪郭だけを開く選択肢を提示する。高度な段落組版・絵文字シーケンスの合成は含まない。

元の著作権・ライセンス情報は保持する。プロジェクトへ格納しても、入力フォントへアプリのMITライセンスを適用しない。

## 検証

Rustワークスペース506テスト成功（実GPU等の16件は通常実行で除外）。gvar／CFF2の範囲・既定値変更、avar、HVAR／MVAR、全軸固定、fvarの名前参照、可変WOFF2、Undo／Redo・保存・復旧を検証した。可変カーニング・合字・IVSを静的化後のHarfBuzz試し組みでも確認した。

独自のCOLRv1可変テスト書体で、VarStoreによる透明度・可変輪郭・パレット編集を確認。保存・復旧後のgvar／CFF2カラーを実Metal GPUで読み戻して成功。Clippy、TypeScript／Vite、自己完結検査、三言語×通常幅／380px幅の操作も成功した。

# フォントの複数選択・一括変換

## 操作

1. フォントライブラリのチェックボックスで複数のフェイスを選ぶ。通常の行クリックは単独選択、⌘/Ctrlクリックは切替、Shiftクリックは現在ページ内の範囲追加。「このページを選択」と「選択を解除」も利用できる。
2. 下部の出力形式を選ぶ。一括変換欄に選択数と出力形式を表示する。
3. 一括変換のフォルダーアイコンを押し、保存先の親フォルダーを選ぶ。
4. 新しく作られた`Fonts-converted-<時刻>-<番号>`フォルダーへ出力する。完了後の成功・失敗表示を開くと、元ファイル・フェイス番号・出力先・個別エラーを確認できる。

- 🟢 [Done] チェックボックス・修飾キーによる複数選択。ページ移動・検索・保存元の切替後も選択を保持する。再スキャン時はカタログIDが変わるため選択を解除する。
- 🟢 [Done] フォントファイル選択ダイアログも複数ファイルに対応。TTC/OTC等はカタログのフェイスごとに選択する。
- 🟢 [Done] 1回1〜256フェイス。TTF、OpenType CFF/CID-CFF、Type1 PFA/PFB、CID Type1、CFF/CID-CFF、Unicode→CID CMapなど、既存の静的変換形式を利用する。
- 🟢 [Done] 変換はRust workerで1フェイスずつ実行し、入力バイト列・輪郭・出力バイト列をJSへ渡さない。制作中の文書を置き換えない。
- 🟢 [Done] 元データ・既存ファイルを上書きしない。出力用サブフォルダーはcreate_dirで新規作成し、ファイルはcreate_newで確保する。ファミリー・スタイル・フェイス番号を保存名に含め、衝突時は連番を付ける。Windowsの予約名等を避けるため接頭辞を付け、区切り文字や予約記号を除去する。
- 🟢 [Done] OS／Adobe等の既存のフォント保存ディレクトリを出力先にしない。既存の保護判定を使用する。インストールとは独立した操作。
- 🟢 [Done] 進捗と現在の書体、個別の成功・失敗、中止処理中の状態を表示する。通常の変換エラーでは後続処理を継続する。
- 🟢 [Done] 中止はフェイスの処理前と変換後に確認。すでに保存済みの成果物は残す。実行中の重い変換やファイル書込を途中で破壊的に打ち切らないため、中止が即時には完了しない場合がある。
- 🟢 [Done] バッチ専用の実行ガードを使い、制作中の文書の自動保存を妨げない。バッチ中の通常終了は防ぎ、中止・完了後に終了できる。ライブラリのウインドウを閉じてもRust側で進め、再表示時に状態を取得する。
- 🟢 [Done] 英語・日本語・简体中文の操作ラベル・結果表示。

## 制約

変換内容は[font-formats.md](font-formats.md)と共通。静的輪郭・基本メタデータの変換であり、可変軸・高度な組版・カラー等を完全に保持する変換ではない。CIDのUnicode対応には適切なCMapが必要となることがある。

選択・進捗・結果一覧はアプリ実行中の状態であり、異常終了後のバッチ再開機能はない。プロセス強制終了やストレージ障害の際に書込途中のファイルが残る可能性がある。文書の自動復旧はこのバッチとは独立して継続する。

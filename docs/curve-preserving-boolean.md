# 曲線保持型ブール演算（2026-11-05）

## 利用方法

🟢 [Done] 輪郭パネルの合成・差分・共通部分・排他的合成が二次／三次ベジェを保持する。Aの閉輪郭をチェックし、単一のBまたは事前に設定したBの輪郭群と演算する。A/Bとも非ゼロ巻き数で穴を扱い、対象外の輪郭はIDを含めて保持する。既存のアイコンを使い、対応範囲は英語・日本語・简体中文の情報アイコンに表示する。

操作はRust workerで計算し、確定時にepoch・glyph・revision・編集中状態を再検証する。確定結果は既存のwgpu描画に直結し、端点・曲線ハンドルも通常のノードツールで編集できる。1回のUndo/Redo、手動保存、自動保存・復旧、TTF／OTF出力へ接続する。WebViewは命令・状態のみを受け渡し、曲線の正本・計算・描画はRust側で保持する。

## 数値処理

1. 直線・二次・三次ベジェの原区間とパラメーター範囲を記録する。包含関係にある同一曲線区間は、次数上げした制御多角形の照合で確認し、分割位置と判定用の細分化を共有する。片方だけ途中で分割された同一境界に不要な細長い領域を生成しない。
2. 位相判定だけを0.001フォント単位の適応的細分化とi_overlayのi64エンジンで行う。入力・出力の共線点を保持し、各出力辺を元の区間と対応付ける。BVHで候補を絞り、同じ原区間の連続する辺を統合する。
3. 接続位置のパラメーターを元の曲線上で補正する。局所範囲内の減衰付きNewton法を使い、接続誤差を1e-7フォント単位以内にする。補正後の区間順序も検証する。
4. de Casteljau分割で残る曲線区間を再構成し、進行方向が逆なら制御点を反転する。二次は二次、三次は三次の原区間として出力する。境界で共有する終点は残差の中点に統一し、接続誤差の範囲だけ位置を補正する。

曲線の輪郭形状を保持する実装であり、記号演算による厳密な位相判定ではない。0.001単位に近い極小形状・非常に接近する境界の位相は許容誤差の影響を受ける。複雑な部分一致、極端な接線接触、局所交点の分離が困難なケースでは接続を確定できないことがある。区間対応や接続が確定しない場合は`boolean_curve_ambiguous`として拒否し、文書・履歴を変更しない。直線化して成功扱いにするフォールバックはない。

入力は細分化後8192点、出力は位相判定点32768点まで。再帰深度24、交点候補100000、辺候補比較2000000、同一曲線の包絡比較2000000・詳細照合16384、区間検索4000000訪問の上限を持つ。上限超過は既存の三言語エラーで扱う。

演算で置き換える輪郭には新しいUUIDを付ける。原輪郭への参照はUndoで復元し、対象外のIDには影響しない。結果の滑らか制約フラグは初期状態とするが、ベジェの接線そのものは原区間の分割で保持する。保存形式は既存のプロジェクトv2のまま。`serde_json`の`float_roundtrip`を有効にし、演算で得たf64座標がJSON保存・再読み込みで最下位桁まで往復するようにした。追加パッケージはない。

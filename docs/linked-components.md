# 安定IDに基づく部品の参照配置・共有更新

## 操作

🟢 [Done] 「部品・スニペット」パネルに「独立スニペット」と「参照部品」のタブを設けた。タブ・部品選択・配置中状態はRustのModelで共有し、ドッキング／フローティングの各ウインドウは定義や配置の正本を持たない。英語・日本語・简体中文に対応し、説明は情報アイコンへまとめた。

1. 通常の輪郭をチェックし、部品名を入力して＋で登録する。元輪郭を消しても登録定義と配置は残る。名前・タグで検索でき、改名は参照を壊さない。
2. 部品を選び、参照配置アイコンから位置・幅・高さ・角度を調整する。既存のwgpuプレビューと移動・拡縮・回転ハンドル、数値入力を使用し、確定／Escで確定・取消する。初期サイズはUPM換算する。
3. 編集元へ移動し、通常のノード・パス編集で原輪郭を加工する。更新したい輪郭をチェックして共有更新アイコンを押す。**編集元の通常編集だけでは配置を変更せず、共有更新で全配置へ反映する。** 定義が新しい寸法になっても配置の行列を保持するため、その寸法変更が反映される。外接矩形へ再正規化して隠す処理は行わない。
4. 利用先一覧から該当グリフへ移動し、その配置を変形できる。参照解除では現在の形と点IDを保った独立輪郭になる。使用中の部品定義は削除を拒否し、解除後に削除できる。

参照中の輪郭は直接ノード加工できない。選択は可能だがドラッグでは動かず、輪郭パネルの編集操作は無効になる。一括加工・ブール演算等からの書き換えもRust側で拒否する。直接加工する場合は利用先一覧で参照解除する。部品を作る元として参照中の輪郭を選んだ場合も拒否し、初期実装では入れ子を作れない。

登録元が分割・削除されている場合、編集元へ移動する操作は残る輪郭UUIDを探す。必要に応じて新しい通常輪郭もチェックして定義を更新する。元輪郭が全て失われても、部品と参照配置は独立して保持する。

## Document・ID・描画・出力

`FontDocument.components`にUUIDをキーとする定義・配置を保存する。定義はInfo・UPM・輪郭・編集元グリフ、配置は定義UUID・配置先グリフ・6要素のアフィン行列・元ノードUUIDと配置先UUIDの対応表を持つ。定義内の元ノードIDは定義UUIDの名前空間で扱い、配置先の点・制御点・輪郭には文書内で一意の別UUIDを付ける。

共有更新では、生き残る元ノードUUIDの対応を再利用する。追加点は新しい配置先UUID、削除点は参照切れとなる。定義の分割・連結に伴う輪郭・端点の別名も配置先に引き継ぎ、Undoで以前の定義・配置・UUID対応を戻す。ID対応表はArcで共有し、メタデータ編集や履歴保持で大きな対応表を常に複製しない。削除済みIDの対応も容量上限内で保持する。

定義が正本で、配置先グリフの輪郭はその変換結果を保持する。更新・変形は全利用先をまとめて検証して確定する。通常の単一グリフ編集は既存の参照輪郭との一致を確認し、変換の再計算を毎ドラッグに実行しない。ファイル読み込み・保存・共有更新の全体検証では、定義から再計算した結果との一致を確認する。不明な定義、欠けた配置先、nil／重複ID、不正行列、不一致の輪郭を拒否する。

同じグリフ輪郭をwgpuの本描画・一覧サムネイル・試し組み・フォント出力へ渡すため、出力時だけ別の形へ展開する経路は設けない。定義サムネイルもRustの既存wgpu workerと容量制限付きキャッシュで生成し、epoch／revision付きネイティブ画像URLで表示する。JavaScriptのIPCにフレームを送らない。TTF／OTF／WOFF2には通常の輪郭として出力し、参照形式を保つフォントの最適化は別工程。

配置UIは移動・非等方拡縮・回転を扱う。コアの変形は一般アフィン行列に対応するが、反転・シアーを持つファイル上の配置は、このUIで変形し直す際に拒否する。表現できない行列を黙って置き換えない。

## 保存・Undo・制限

🟢 [Done] 部品を導入した文書はプロジェクトv3で保存する。v1／v2は引き続き読み込み可能で、部品がない通常の新規文書は従来のv2を使う。旧ファイルを開いただけではv3へ上書きしない。v3文書には対応版アプリが必要。定義と変換済み輪郭、UUID対応を埋め込み、外部ファイルに依存しない。

登録・改名・参照配置・共有更新・配置変形・参照解除・未使用定義の削除はそれぞれ1回のUndo/Redoになる。履歴は変更グリフと部品データを保持し、全利用先を一括して戻す。初回登録のUndoでは以前のschemaも復元する。変更せずに配置変形を確定した場合は、行列と履歴を増やさず保持する。保存・復旧後もUUIDと参照を保持する。選択や未確定プレビューは一時状態で、再起動時にUndo履歴やプレビュー自体を復元する機能ではない。

部品は256件、各128輪郭／16384点、定義全体65536点まで。配置は文書全体4096件、ID対応は1配置65536件・全体1000000件まで。既存のグリフ輪郭数・座標・保存容量上限も適用する。行列は有限かつ行列式の絶対値1e-12以上とし、変換後の座標を検証する。容量超過・競合・失敗時は文書と履歴を変更しない。

# TrueType合成グリフと参照部品

🟢 [Done] 2026-11-06。ヘッダーの部品読み込みアイコンから、静的TrueTypeの合成グリフを参照部品として読み込める。TTF／TTCとTrueType WOFF2に対応し、コレクションは収録書体を選べる。普通のフォント読み込みと「開く」は従来の輪郭として読み込む操作を維持する。英語・日本語・简体中文へ接続した。

## 読み込みと編集

`glyf`／`loca`を上限付きで解析し、単純グリフのon/off-curve点から二次輪郭を構築する。複数のoff-curve点が続くときは暗黙の端点を補う。合成グリフのbyte／word引数、平行移動、等方／非等方拡縮、2×2行列、拡縮する／しないオフセット、実点同士の位置合わせ、入れ子を扱う。既定オフセットはMicrosoft／Appleと同じ非拡縮の解釈を使用する。[OpenType glyf仕様](https://learn.microsoft.com/en-us/typography/opentype/spec/glyf)に基づく。

ヒンティングは実行・持ち越しせず、デザイン座標へ変換する。`USE_MY_METRICS`があるグリフの送り幅は同梱FreeTypeのNO_SCALE／NO_HINTING／NO_BITMAPで解決する。通常の静的TrueType読み込みも同じ輪郭・メトリクス補正を使用し、点合わせやscaled offsetを取りこぼさない。

参照先のグリフを安定UUIDの定義へ変換し、親の子部品・各グリフの配置へ接続する。元グリフは独立した輪郭として残し、共有編集は定義の専用モードで行う。wgpu描画、親・祖先・配置先の更新、操作単位Undo/Redo、v3／v4の埋め込み保存・復旧をそのまま利用する。ライセンス本文は文書のフォント情報に保持し、2048 byteを超える本文を部品欄へ不完全に切り詰めて複製しない。

読込・解析・変換はRust workerで実行し、新しい未保存文書として開く。元ファイル・既存文書は変更しない。収録書体の選択中は元の読み込みモードをRust側へ保持し、別ウインドウからの参照は拒否する。バイナリはWebViewのIPCへ送らない。

## 出力

出力画面でTTFまたはTrueType WOFF2を選び、「参照部品を合成グリフとして出力」を有効にする。通常の輪郭出力も選べる。他の形式では輪郭出力を維持する。

必要な定義を依存順に処理し、親子関係・共有を保持した合成グリフへ変換する。元グリフの形が一致していて参照配置を含まない場合は、そのグリフを再利用する。元がない場合や形が異なる場合は、Unicode未割当の補助グリフを追加する。親に通常輪郭が混在する場合も専用の補助グリフへまとめる。再読み込み後の補助グリフは再利用し、同じ部品を出力するたび無条件に増やさない。

部品と配置の変形は、線形部分がF2Dot14、移動量が符号付き16bit整数で正確に表せる場合に出力する。対応範囲を超える値は丸めて確定せずエラーにし、通常の輪郭出力または変形の調整を促す。明示的な非拡縮オフセットを使用し、輪郭順序に基づく配置順を保つ。補助グリフは元のGlyph ID順序の後に追加し、Unicode・既存カーニングの対応を維持する。

`maxp`の複合点数・輪郭数・参照数・入れ子深度と、`glyf`／`head`の外接矩形を再生成する。チェックサムと送り幅・Unicode・全グリフ数を読み戻して検証し、保存後はファイル内容の一致も確認する。WOFF2では復号も検証する。自動ヒント生成も選択でき、元の命令の流用は行わない。出力用の補助グリフは作業中の文書・履歴・プロジェクト保存へ混入しない。

## 制限

入力は最大256 MiB、展開した総点数1600万、1グリフ65535点／4096輪郭、1グリフ4096参照まで。参照経路は最大17グリフ（プロジェクトの16段の定義＋配置元）とし、評価済みの子を再利用する経路にも深さ検査を適用する。循環、欠落、壊れたloca・引数・命令長、予約フラグや矛盾した変形フラグを拒否する。

プロジェクト側は定義256件、各128輪郭／16384点、定義全体65536点、子リンク4096件、配置4096件など既存の制限を適用する。大規模な合成フォントが上限を超える場合は、通常の輪郭読み込みを使用できる。可変TrueTypeは既定値の通常読み込み、または静的インスタンスへの変換を経由する。カラー、特異行列、phantom pointによる点合わせ、回転を伴う未定義のメトリクス継承は本モードの対象外とし、明示的に拒否する。編集用の部品構造への変換で、元のヒンティング・グリッドフィット動作自体を再現するものではない。

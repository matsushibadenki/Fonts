# 取り込み済み組版情報・縦組み・IVS

静的なOpenTypeのGSUB・GPOS・GDEF・BASE・JSTF・kern、縦組みメトリクス、cmap format 14を文書へ保持する。元ファイルへのリンクではなくプロジェクト内に格納し、保存・自動復旧後も参照できる。プロジェクト形式はv5で、旧形式も読み込める。

## 編集と出力

- 🟢 [Done] 全グリフの順序を維持し、TTF／OTF／WOFF2へ保持する。末尾へのグリフ追加に対応し、元グリフの削除・順序変更・UPM変更は出力時に拒否する。
- 🟢 [Done] 外部の位置調整を保持している間はペア／クラスカーニングをロックする。解除ボタンで元の位置調整を除き、編集可能にする。字形置換・IVSは保持する。フォント情報では組版情報全体を解除できる。解除は文書単位のUndo／Redoに対応する。
- 🟢 [Done] 輪郭再構築で古くなる点参照は読み込み時にヒントなしの設計座標へ変換する。GPOSの点アンカー、BASEの点アンカー、GDEFの合字キャレットに対応する。共有キャレットはグリフごとに解決する。
- 🟢 [Done] 標準の縦組みメトリクスを生成し、読み込んだ独自のvhea／vmtx／VORGは保持する。形式変換時は縦送り・縦原点を引き継ぐ。
- 🟢 [Done] 保持上限はテーブル合計32 MiB。未対応の点参照や上限超過では明示的に拒否し、「元の組版情報を除く」で輪郭だけを開き直せる。生CFF／Type 1は組版テーブルを格納できないため、解除するまで出力を拒否する。

元テーブルの字形置換ルールやアンカー自体をGUIで編集する機能ではない。可変フォントは既存の静的インスタンス変換機能を使用する。カラー・ヒンティングもそれぞれ専用機能を使用する。

## 試し組み

- 🟢 [Done] 同梱HarfBuzzを使用し、実際に生成したフォントの合字・位置調整・IVS・結合文字を配置する。Unicode双方向処理と文字体系ごとの組版を行う。
- 🟢 [Done] 横組み／右から左への縦組み、言語、自動回転／全正立、列の高さを三言語UIから設定する。Unicode 17のVertical_Orientationに従い、縦字形がない回転対象は90度回転する。
- 🟢 [Done] 書き出しバイト列、組版結果、輪郭、GPUバッファはRustに保持する。WebViewとの通信は設定と状態のみ。合字・IVSをクリックすると実際に置換されたグリフの編集へ移る。
- 🟢 [Done] 結合文字を含むクラスタの内部へ字間を挿入しない。英語等の語単位とCJKのクラスタ単位で折り返す。高度な禁則処理や段落均等配置は含まない。
- ⭕️ [Pending] Windows／Linuxの実画面と、広範な実フォント・外部組版アプリとの表示比較。

テスト用の輪郭と組版フィクスチャは独自作成したMITのデータであり、生成スクリプトを同梱する。UnicodeデータのライセンスはREADME末尾と同梱ライセンス一覧へ記載する。

## 検証

通常Rustテスト495件、Clippy、TypeScript／Vite、自己完結検査が成功。TTF／OTF／WOFF2の組版テーブル保持、共有キャレットの分離、合字・結合文字・IVS・縦字形・回転・双方向配置、字間とクラスタ、保存・自動復旧・Undo／Redo・実際の置換先へのクリックを検証した。実Metal GPUから縦字形・回転グリフの画素を読み戻して成功。三言語×通常幅／380px幅のUI操作も確認した（Browserプラグインが利用できないためPlaywrightを使用）。

# 実フォントの試し組み

## 操作

メイン画面の「試す」を押すと、制作中の文書から生成した静的TrueTypeの文字セットをネイティブGPU画面に表示する。「描く」で編集へ戻り、または現在側の文字をクリックすると対応する元グリフを開く。

- 🟢 [Done] 任意の文字列、文字サイズ12〜160、字間−0.1〜1 em、行間0.8〜3、改行・横幅に応じた折り返しとスクロール。
- 🟢 [Done] 文字列変更は350 msまとめてから更新。文書の編集が確定した場合も再生成する。
- 🟢 [Done] 実際の静的TTF出力をメモリ内で生成し、再読込した輪郭・Unicode対応・送り幅を使用する。OSにインストールされている同名フォントを代用しない。TTFの整数座標化・三次曲線から二次曲線への近似も反映する。
- 🟢 [Done] 必要な文字に対応するグリフと.notdefだけを抽出し、フォント生成をRust workerで実行する。生成バイト列・輪郭・GPUバッファはRust側に保持する。WebViewとの通信は文字列・設定・状態・操作のみ。
- 🟢 [Done] 見本を固定して、現在の出力と左右に並べる。固定後に輪郭・送り幅を編集して再び試すと、現在側だけが更新される。比較を解除して単独表示へ戻せる。
- 🟢 [Done] 未収録文字は色付きの枠と斜線で表示し、件数とコードポイントを示す。収録済みだが輪郭がない文字の件数も表示する。別書体のフォールバックで欠けを隠さない。
- 🟢 [Done] epoch/revisionと生成リクエスト番号で古い結果の適用を拒否。別文書へ切り替えた際は生成済みフォントと比較用コピーを解除する。試し組み設定は編集Undoや文書の保存済み状態を変更しない。
- 🟢 [Done] 英語・日本語・简体中文のGUI。説明は情報アイコンのツールチップに置く。

## 対応範囲・制約

- 最大2,048 Unicodeスカラー／16 KiBのサンプル。文書全体ではなく現在のサンプル用の静的TTFサブセットを使う。比較用見本も固定時のサンプルに収録されたグリフのコピーであり、固定後に別の文字を入力すると比較側では未収録となることがある。
- 横書きのスカラー単位の配置を実装。英数字の語をまとめて折り返し、CJKは文字ごとに折り返す。高度な禁則処理、Unicode双方向配置、結合文字の位置合わせ、外部のGSUB/GPOS・合字・class kerning・異体字シーケンス・縦組みは 🔴 [Later]。現在の静的出力が保持しない組版情報を、元の書体と同等に再現する機能ではない。
- サイズ・字間・行間・サンプル・比較見本はRustのセッション状態であり、プロジェクトJSON・自動復旧へは保存しない。文字の形や送り幅そのものは通常の文書として保存する。
- 輪郭を閉じるなど、実際のTTF出力条件を満たす必要がある。生成失敗時は前の有効な表示を保持し、エラーを示す。
- 輪郭は4x MSAAのネイティブwgpuで表示する。OSの文字ラスタライザーやヒンティングとは異なる。現行の文字内の塗りはエディターと共通のeven-odd方式であり、自己交差・重複輪郭のある書体を含めた外部アプリとの完全一致は保証しない。文字間では塗りを独立させ、比較表示を列の範囲でクリップする。
- 可視部分を描画し、生成頂点数に上限を設ける。異常に複雑な書体では明示的にエラーとなる。常時アニメーションは行わない。
- ⭕️ [Pending] Windows/Linux実機のネイティブ描画・試し組み、外部アプリとの表示比較。

## 検証

通常Rustテスト214件、Clippy `-D warnings`、型検査・フロントエンドビルドが成功。テストは生成TTFの送り幅・補助平面・未収録文字・折り返し・入力上限・元グリフへのクリック対応・文書切替時の比較解除を含む。

実GPUの読み戻しテストで、文字の穴と別グリフによる重なりを確認。macOSの独立したFonts Proof QAアプリで、試すへの切替、文字列変更、96の文字サイズ、未収録の「?」、固定見本との比較、文字クリックで編集へ戻る操作を確認。送り幅640→900の変更が現在側にだけ反映され、比較側は640を保持することを画面で確認した。

🟢 [Done] 作成した横組みの明示ペアを試し組みへ反映する。AVアイコンで適用／無効を比較でき、固定見本は当時の値を保持する。[ペアカーニング](pair-kerning.md)。

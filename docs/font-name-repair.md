# PostScript名とCFF名

🟢 [Done] 静的OTF／CID-OTFの書き出しでは、name ID 6とCFF Name INDEXに同じ共通生成値を使用する。表示用のファミリー名・スタイル名は別に維持する。CFFベースのWOFF2も同じ生成経路を通る。

フォントライブラリ上部のチェックアイコン「フォント名称の検査」からフォルダーを選ぶ。サブフォルダーを含めて、不一致・一致・対象外・不正を表示する。不一致を確認して「修正コピーを保存」を押すと、各元ファイルの親フォルダー内の `Fonts-NameFixed` に同じファイル名で保存する。元ファイルと既存の出力は上書きしない。英語・日本語・简体中文に対応。

対象は単体SFNTのCFF1。CFF2にはName INDEXがなく、TTC／OTCとWOFF／WOFF2、単体CFFは今回のフォルダー修正対象外。name ID 6のレコード同士が矛盾している場合は、どれかを推測で採用せず不正として表示する。名前が一致しているファイルには変更を加えない。

修正ではCFFの新しいヘッダー・Name INDEX・Top DICTを構築し、文字列・GlobalSubrsを保持して元データを後置する。絶対オフセットとCIDのFDArray／Private参照を再配置し、輪郭のCharStrings、ローカル／グローバルSubrs、相対参照を変更しない。他のSFNTテーブルは保持し、DSIGは無効になるため除去する。headのチェックサム調整値とディレクトリーを再構築する。保存後に読み戻して全バイト一致を検査する。

走査は最大1000ファイル／待機ディレクトリー、合計512MiB、深さ8、ディレクトリー項目20000まで。上限到達時は部分結果と表示する。シンボリックリンクと既存のFonts-NameFixedは走査しない。検査結果はRustが保持し、修正要求には世代番号だけを渡す。修正時に元ファイルの名称を再検査し、検査結果と異なる場合は拒否する。

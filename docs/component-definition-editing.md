# 部品定義の専用編集モード

🟢 [Done] 2026-11-06。参照部品パネルの鉛筆アイコンで、選択した部品定義をキャンバスへ開く。編集元グリフ・元の輪郭がなくても利用できる。上部バーに定義名と終了アイコンを表示し、終了時は元のグリフと表示位置・倍率・ツールへ戻る。子定義・親定義へ移動して編集対象を切り替えられる。英語・日本語・简体中文に対応する。

## 編集と共有更新

ペン、アンカー／制御点の複数選択・ドラッグ・数値一括加工、滑らか／角、開輪郭の継続・連結、分割、反転・閉鎖・直線化、曲線保持ブール演算を既存の編集経路へ接続した。パス貼り付けはキャンバスへ縦横比を保って収める。独立スニペットの配置・選択輪郭の登録、子部品の参照配置にも対応する。部品定義は1輪郭以上を保持し、全輪郭を消す変更は拒否する。

変更は各操作の確定時に定義・祖先・参照配置へ反映し、1操作を文書単位のUndo/Redoへまとめる。終了ボタンは編集モードから戻る操作であり、セッション全体を破棄する操作ではない。Escapeは現在の仮描画・ドラッグ・配置を取り消す。未確定操作がある間は定義の切り替え・終了を拒否する。

子部品から投影された輪郭は直接加工しない。子定義を開くか、子の参照を解除してから加工する。追加する子は既存の循環・16段・展開量・ID整合性検査を通す。定義変更の失敗時は文書・履歴を変更しない。部品の編集中はグリフの送り幅・Unicode・カーニング・確認済み状態・アタリ画像・試し組みの変更を禁止し、背後のグリフへ誤適用されることを防ぐ。アタリ画像は本モードでは表示しない。

## Rust所有の編集対象

本来のEditorとFontDocumentを維持し、Modelに編集対象の定義UUIDと派生キャンバスを保持する。表示専用のGlyphは実文書へ挿入しない。描画・ヒットテスト・点選択・演算は派生キャンバスを参照し、確定時は定義を直接更新する。wgpuは通常の編集メッシュ・ノード・制御点・配置枠をそのまま描画する。フレームデータをJavaScriptへ転送しない。操作ごとに画面が跳ねないよう、キャンバス範囲は全体表示を実行するまで保持する。

定義UUIDを切り替えるたび文書epochを進める。モード変更前のポインター操作・非同期演算結果を古いepochで確定できない。フローティングパネルも同じRust状態を参照する。

部品のローカル点IDは編集元の点IDと同じ値になり得るため、NodeRefに省略可能な`definition` UUIDを追加した。部品の点参照は文書UUID＋定義UUID＋点UUIDで解決し、通常グリフの名前空間へフォールバックしない。既存のグリフ参照のJSON表現は維持する。復旧後の有効な部品点参照は対応する編集モードを開ける。

## 保存と復旧

保存・自動復旧・フォント出力は本来のFontDocumentを使用する。定義と全配置先の変更を埋め込み保存し、編集用グリフや画面状態は混入しない。既存のv3／v4形式を利用し、新しいschemaを要求しない。再起動後は通常のグリフ画面から、保存済みの定義を再び開く。メモリ内Undo履歴・未確定操作・専用モード自体は再起動時に再開しない。

# 輪郭の点の追加・削除

輪郭パネルの各輪郭で、終点座標付きの区間を選び、＋で中間点を追加、−で終点を削除する。英語・日本語・简体中文に対応。説明は情報アイコンで表示する。

## 動作

- ＋: 直線・二次曲線・三次曲線をパラメータ t=0.5 で二分割する。de Casteljau法により曲線形状を保持する。輪郭の開閉状態は保持する。
- −: 選択区間の終点と、その点へ入る区間を除去する。次の区間は種類と制御点を保持したまま、前の点から接続する。曲線の形は変わる。自動近似やハンドル調整は行わない。
- 始点と明示的な閉鎖用の重複終点は削除対象にしない。閉輪郭は最低3つの端点、開輪郭は最低1区間を保持する。座標の一致による退化や自己交差の自動修正は行わない。
- 現時点では保存された区間が対象。暗黙の閉鎖線（最後の端点から始点へ戻る線）は区間一覧に含めない。
- 1操作を1回のUndoに記録する。Redo、JSON保存、自動保存、既存のフォント出力に反映する。

## 状態の所有と安全性

幾何処理と文書更新はRustで実行する。WebViewは区間番号とコマンドのみ送信し、Rust所有の文書を編集する。点・輪郭の永続IDは今回導入しない。既存のepoch/revisionによる競合検査を使い、ドラッグ・ペン作図中、別グリフ、不正な区間、古いrevisionからの変更は文書へ反映しない。区間数上限65,536を守る。

## 検証

Rustの自動検証では直線・二次・三次分割前後を101点で比較し、閉鎖点保護、最小輪郭、不正区間での状態保持、後続ハンドル保持、競合拒否、作図中の拒否、Undo/Redo、JSON往復、TTF出力・再読込を確認する。

検証結果: 通常Rustテスト223件成功（既存の任意テスト3件はignored）、Clippy `-D warnings` 成功。独立したmacOS検証用アプリ（1280×820）で、輪郭の8→9ノード追加、9→8削除、Undoの9ノード復元、Redoの8ノード復帰と、最小輪郭の削除ボタン無効化を確認した。wgpu描画上でも追加した点と形状保持を目視確認した。

## 滑らか／角と選択点の連動

キャンバスのノードをクリック、または輪郭パネルの座標一覧から端点を選ぶ。選択はRustのModelが所有し、全ドッキング／フローティングパネルのSnapshotへ配信する。選択点をwgpuで青い枠として描く。ハンドルを選んだ場合、キャンバスではそのハンドルを囲み、パネルでは接続先の端点を選ぶ。空白クリック、グリフ切替、Undo/Redoで選択を解除する。

- 「滑らか」（◡）: 隣接する2本のハンドルを一直線に揃え、各ハンドルの長さを保持する。出側ハンドルの方向を基準とし、出側が長さ0の場合は入側の方向を使う。両方が長さ0なら変更を拒否する。以後、片側のドラッグで反対側を回転し、反対側の長さを保持する。左右同じ長さにする「対称」制約ではない。
- 「角」（⌃）: ハンドル位置を変えずに連動を解除する。見た目が滑らかなままでも角として独立編集できる。
- 二次曲線・直線は、切替対象の両隣だけ三次曲線に変換してからハンドルを揃える。二次→三次の変換自体は形状を保持するが、接線の整列により最終的な形は変わる。
- 閉輪郭の暗黙の閉鎖線は「滑らか」切替時に明示的な直線として追加する。始点と重複閉鎖終点は同じ端点として扱う。開輪郭の始点・終点は滑らかに切り替えられない。
- 点の追加は選択端点へ入る区間を分割する。始点を選んだ場合は最初の区間を分割する。三次曲線の分割中間点には滑らか制約を設定する。削除では削除した端点および接続が変わる直前の端点の制約を解除し、他の制約の番号を更新する。

検証: 通常Rustテスト226件とClippy `-D warnings` 成功。接線の整列、両方向のハンドル連動、反対側の長さ保持、角への解除、端点移動、暗黙閉鎖線・始点、旧JSONとの互換性、番号更新、キャンバスからの選択、revision競合、Undo/Redoを自動検証した。

各Contourの`smooth`に端点番号を保存する。従来のプロジェクトで項目が存在しない場合は空集合（独立したハンドル）として読む。文書の永続UUID・安定node IDは未導入で、epoch/revisionで番号の有効性を守る。プロジェクト保存・復旧コピーでは制約を保持するが、TTF/OTF等の出力に編集用制約は含まれず、輪郭形状として反映する。再インポート時の滑らか属性の自動判定は行わない。

macOS実画面（1280×820）の独立検証アプリで、キャンバス端点→パネル、ハンドル→接続端点、パネルの座標一覧→キャンバス青枠の双方向連動を確認した。滑らか切替後に片側ハンドルをドラッグして保存し、JSONの接線ベクトルの正規化外積が約1.3×10⁻¹⁶であることを確認。「角」への切替・再保存後は制約が消え、全区間の座標が同一であることも検証した。TypeScript/Viteと通常版macOSアプリのビルドも成功。Windows/Linux実画面は引き続き⭕️ [Pending]。

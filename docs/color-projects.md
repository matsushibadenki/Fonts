# カラープロジェクト

ライブラリのカラーフォント画面で「カラーのコピーを編集」を押すと、元ファイルを変更せず専用の文書を開く。COLRv0／COLRv1／SVG／sbix／CBDTをプロジェクトv6へ格納し、元ファイルがなくても保存・自動復旧後にプレビュー・出力できる。旧v1〜v5も読み込める。

- 🟢 [Done] CPALのパレット切り替え、色と不透明度の編集、元の色への復元。1回の適用を1回のUndo／Redoにまとめ、文書ごとに独立させる。パレットの選択も保存・復旧する。
- 🟢 [Done] 多数の色は64色ずつ表示し、色番号を直接指定して移動できる。共有された色レコードは出力時に独立させ、別パレットを意図せず変更しない。
- 🟢 [Done] Rust workerが編集後のフォントからプレビューを作り、wgpuへ描画する。WebViewへ元フォントや画素を転送しない。古いepoch／revisionの結果は拒否する。読み込み中やプレビュー非対応時に単色輪郭を代わりに表示しない。
- 🟢 [Done] 元と同じTTF／OTF、および圧縮設定付きWOFF2へ出力する。保存ダイアログ・出力前の全テーブル検証・保存後の読み戻しへ接続する。元のCOLR・SVG・ビットマップ・組版・可変・ヒンティング等は保持する。
- 🟢 [Done] 英語・日本語・简体中文のコンパクトな操作画面。通常の輪郭・メトリクス・カーニング・部品・フォント名の編集はロックし、専用編集と元データの不整合を防ぐ。

CPALの色を参照する描画が編集対象となる。SVG内へ直接書かれた色、埋め込み画像の画素、レイヤー構造や描画プログラムは保持する。これらを直接描き直す機能は含まない。プレビューの文字対応とSVGの安全性は既存の[対応範囲](color-fonts.md)に従い、複雑な絵文字シーケンスの合成は行わない。

埋め込みフォントは1文書128 MiB、変更できる色は合計4,096件まで。選択したTTCフェイスだけを格納する。元のライセンス情報を保持し、アプリのMITライセンスを入力フォントへ適用しない。

## 検証

Rustワークスペース499テスト成功（実機用15件は通常実行から除外）。共有レコードの分離、色・透明度・テーブルの保持、TTF／WOFF2出力、CFF・SVG・ビットマップの埋め込み、Undo／Redo、保存・復旧、Rust側への画素保持を検証した。保存後の編集色を実Metal GPUで読み戻して成功。Clippy、TypeScript／Vite、自己完結検査、三言語×通常幅／380px幅のUI操作も成功した。

# 画像トレース

🟢 [Done] 配置したPNG/JPEGの白黒輪郭トレース。アタリ画像パネルで画像を選択し、「画像トレース」を開く。しきい値、反転、最小面積、簡略化を設定し、目のアイコンでプレビュー、チェックで輪郭を追加、×で取り消す。説明は情報アイコンに集約する。英語・日本語・简体中文に対応。

処理はRust workerで行い、画像・画素・全輪郭をIPCへ送らない。Rust所有の一時グリフを通常のwgpu描画へ渡す。確定前のプレビューは文書・出力・保存・自動復旧データを変更しない。確定時には通常の編集可能な閉じた輪郭を追加し、元画像と既存輪郭は保持する。全体を1回のUndo/Redoで戻せる。新しい輪郭・点に永続UUIDを付与し、既存のプロジェクト保存・自動保存・復旧、TTF／OTF／WOFF2出力を利用する。新しい保存形式は不要。

## 抽出方式

RGBを輝度へ変換し、透明度を白地に合成してしきい値で二値化する。完全に透明な画素は反転しても空白とする。画像の表示用透明度・可視性・ロックは抽出する画素を変えない。明るい部分を採取する場合は反転する。

画素境界の有向辺をたどり、斜めに接した領域を分離し、外周と穴に逆の向きを与える。最小面積未満の領域・穴を除去し、同一直線上の点を落としてから閉じた輪郭をRDPで簡略化する。面積は元画像の平方画素、簡略化は元画像の画素単位。画像の位置・縦横の拡縮・回転を適用して、Y上向きのフォント座標へ変換する。

## 範囲と保護

- 白黒の直線ポリゴン輪郭を生成する。色分けトレース、中心線抽出、ベジェ曲線へのフィットは含まない。簡略化を強くすると細部が変わるため、確定前のプレビューで確認する。
- 1画像400万画素、境界50万辺、4096輪郭、65536点。簡略化距離0〜4画素、最小面積0〜100万平方画素。簡略化の距離評価も全体800万回に制限し、それを超える部分は未簡略化の輪郭を用いて点数上限を確認する。複雑すぎる入力は、文書を変更する前にエラーにする。
- 可変・カラーの元フォント保持文書、マスター編集・部品定義編集では無効。静的コピー、通常の静的フォント文書、新規文書で使用する。既存の参照部品の点は変更しない。
- ワーカー終了時にepoch・revision・glyph・選択画像・要求UUIDを再照合する。キャンセル、文書変更・切替、後続要求より遅れた結果を拒否する。プレビューは操作元ウインドウが所有し、別ウインドウからの確定を拒否する。Esc・ツール変更・Undo/Redo等で一時状態を解放する。

## 検証

透明画素と半透明、しきい値・反転、穴と小領域、斜め接触、回転、ノイズ上限、点ID・保存・Undo/Redo、3形式のフォント出力と再読込を自動検証する。Rustモデルでは一時プレビュー、所有ウインドウ、キャンセル後の遅延結果拒否、確定、文書切替、復旧ストア再起動後を確認する。

UIは三言語×幅1000/280pxでプレビュー・取消・確定、空結果のエラーから設定変更して再試行する。Browserスキルが利用できないため、Playwrightとインストール済みChromeで検証する。実GPUの独立テストで抽出輪郭の塗りと穴を読み戻す。

最終結果：Rustワークスペース571件成功・失敗0件（通常実行では18件を除外）。実Metal GPUのトレース輪郭・穴の読み戻しは別途成功。三言語×2幅のUI 6ケースはコンソールエラー・横はみ出しなし。Clippy全targetの警告なし、TypeScript／Vite、整形・差分・自己完結検査が成功。macOSデバッグ版Fonts.appも生成成功（開発ビルドのため更新署名成果物は無効）。

# 部首・図形スニペットと構成部品

🟢 [Done] 漢字の部首や繰り返し使う輪郭を登録・管理し、独立コピーとして配置する機能を実装した。共有更新を伴う構成部品の参照配置は🔴 [Later]。部首はUnicode文字や特定の漢字分類に限定せず、へん・つくり・かんむり等の配置別バリエーションも登録できるようにする。

## 部首・構成部品（参照配置はLater）

- 空の部品を作成するほか、既存グリフの選択輪郭を抽出して登録する。名前、タグ、分類、配置別バリエーション、プレビューで管理・検索できる。
- 部品編集画面で輪郭を編集し、グリフへ参照配置する。位置・サイズ・角度を調整でき、同じ部品を複数回使用できる。
- 参照配置は元部品の変更を利用先へ反映する。利用先一覧と更新の影響範囲を表示する。必要な箇所では参照を解除し、独立した輪郭へ展開して編集できる。
- 複製・改名・バリエーション作成・削除に対応する。使用中の部品の削除は黙って行わず、削除を拒否するか、利用先を輪郭へ展開してから削除する選択肢を提示する。展開と削除は1回のUndoで戻せるようにする。
- 参照には安定したIDを使い、改名や一覧の並べ替えで参照を壊さない。循環参照を拒否する。初期実装では部品内部に別部品を入れる操作を制限し、入れ子参照は後段で扱う。

## 部首・図形スニペット

スニペットは雛形の輪郭をコピーして挿入する。挿入後は独立して編集でき、雛形の変更を既存の挿入先へ自動反映しない。関連する形をまとめて更新したい場合には部品の参照配置を使う。

- 同梱雛形とユーザー登録を区別して一覧表示する。検索、タグ、分類、お気に入り、輪郭サムネイルで探せるようにする。
- ユーザーは選択輪郭や部品からスニペットを登録・複製・改名・削除できる。同梱雛形は直接上書きせず、複製して編集する。
- 基本図形は長方形・楕円・三角形・多角形など、部首はへん・つくり等の初期雛形を用意する。部首の収録範囲は別途確定し、日本語・简体中文・繁体字の字形差を区別する。異なる字形を同じ部首名だけで自動置換しない。
- 配置時にプレビューとバウンディングボックスを表示し、位置・サイズ・角度を調整して確定する。Escで未確定配置を取り消す。元のUPMから配置先UPMへ寸法を換算し、必要に応じて配置先に合わせて拡縮する。
- 登録・利用する雛形には出典とライセンス情報を保持する。同梱素材はプロジェクトで作成したもの、または再配布可能と確認したものに限定する。

## UI・文書・出力の設計

ドッキング／フローティング可能な「部品・スニペット」パネルを実装した。現在は独立コピーのスニペットを扱い、部品参照の導入時にタブを追加する。作成・登録・配置、編集・複製、削除の関連アイコンをグループ化し、機能群の間に区切り線を入れる。説明は情報アイコンのツールチップとし、英語・日本語・简体中文に対応する。

RustのDocument/Stateが部品定義・参照・選択・配置中プレビューを所有し、輪郭とサムネイルはwgpuで描画する。ウインドウ間ではID・命令・状態だけを通信する。ユーザーのスニペットライブラリはRust側で管理し、登録済み雛形の削除が挿入済み輪郭に影響しない設計にする。

プロジェクトには使用中の部品定義を含め、外部ライブラリや元フォントがなくても開けるようにする。配置済みスニペットの輪郭も文書に保存する。登録元の外部ファイルに依存しない。文書操作はepoch/revisionで競合を検査し、Undo/Redo・自動保存・復旧へ接続する。旧プロジェクトは部品なしとして読み込めるよう保存形式を移行する。

初期のフォント出力では参照部品を変換済み輪郭へ展開し、既存のTTF／OTF等の出力経路で書き出す。参照のまま最適化して出力することは後段とする。変換行列、負の行列式による輪郭方向、出力形式の座標・グリフ数上限を確認し、試し組み・一覧・書き出しの字形を一致させる。

## 現在の操作（2026-10-17）

キャンバスの四分割アイコン、右ドックの「部品・スニペット」、または表示メニューのパネルから開く。パネルの見出しは既存パネルと同様にドッキング／分離できる。

- 登録: 輪郭パネルのチェックボックス、またはスニペットパネルの「選択輪郭」で複数の輪郭を選び、＋から登録する。名前・タグ・分類・出典・ライセンスを入力する。閉じた輪郭と編集中の開輪郭に対応するが、面積のない水平線・垂直線だけの登録は拒否する。
- 管理: 登録情報の編集、複製、お気に入り、削除に対応。名前・タグの検索はNFKCで正規化する。同梱／登録／お気に入りと図形／部首／その他を絞り込める。同梱は直接変更せず、複製して登録する。
- 配置: 雛形を選んで「独立コピーを配置」。元UPMから現在のUPMへ換算し、グリフの中央にプレビューする。ドラッグで移動、8ハンドルで拡縮、丸いハンドルで回転する。四隅は縦横比を保持しShiftで自由拡縮、回転はShiftで15°刻み。位置・幅・高さ・角度は数値入力も可能。チェックで確定し、Esc／×で取消。
- 確定後: 通常の輪郭としてノード編集できる。元の雛形、登録元グリフ、他の配置とは連動しない。雛形を改名・削除しても配置済み輪郭を保持する。

同梱は独自作成の長方形・楕円・三角形・ひし形と、「口」「工」を使った幾何形の6件。全てCC0-1.0。地域別字形を網羅した部首書体ではなく、字形差の自動置換はしない。登録時の出典・ライセンスはユーザーが確認した情報を保持する。

## 所有・保存・履歴

`FontDocument.snippets.entries`に登録済み雛形のID、UPM、輪郭、名前・タグ・分類・出典・ライセンス・お気に入りを保存する。文書schema 1に省略可能な`snippets`を追加し、従来の文書は空ライブラリとして読む。外部ファイルやアプリ共通ライブラリには依存しない。別プロジェクトへのライブラリ交換はLater。旧アプリで新しい画像／スニペット入り文書を開く互換性は提供しない。

選択輪郭・選択雛形・配置プレビュー・ドラッグはRustのModelで共有し、epoch／revision／glyphを検証する。ドラッグtokenが古ければ拒否。確定前は文書を変更せず、保存・復旧・出力・試し組みへの混入を防ぐ。Esc、グリフ／ツール切替、Undo/Redo、操作元ウインドウの終了で一時配置を破棄する。ポインターキャンセルはドラッグ開始前の位置へ戻し、配置プレビューを残す。

登録・情報更新・複製・削除はそれぞれ1回のUndo。配置前の複数の変形を含め、配置確定を1回のUndoにする。配置済み輪郭は従来のTTF／OTF等の経路へ入り、未使用の雛形はフォントへ出力しない。

輪郭は不変のArcで履歴・文書スナップショットと共有する。ライブラリは256件、1件128輪郭・16384点（始点＋セグメント終点）、合計65536点まで。メタデータ文字列も制限し、無効な値・上限・古いrevisionで文書や履歴を変更しない。配置先は既存の4096輪郭上限を適用する。

wgpuでプレビューと128pxサムネイルを描画する。サムネイルは既存の容量制限付きworker／LRUを利用し、文書の世代が変われば無効化する。専用のネイティブ画像パスで配信し、WebViewへ輪郭や画素フレームをIPC転送しない。従来の3パネル配置は起動時に4パネルへ移行し、既存の配置とサイズを保持する。

# 複数点・パス分割・ブール演算（2026-11-04）

## 操作

ノードツールでアンカーをShift＋クリックして追加／解除する。選択済みの点を通常ドラッグすると選択点全体を移動する。全選択／解除とX・Yの移動量は輪郭パネル上部。キャンバスの⌘A／Ctrl+Aも全アンカー選択、矢印は1単位、Shift＋矢印は10単位。端点・制御点の混在選択と一括拡縮・回転にも対応（[制御点の一括加工](control-point-batch-editing.md)）。

一括移動は移動前の字形から計算し、閉鎖点の重複アドレスを正規化する。三次曲線の接続ハンドルは各アンカーと一緒に1回だけ移動。二次曲線の共有制御点は両端が選択されているときだけ一緒に移動し、片端だけの場合は従来どおり固定する。全選択で字形全体を移動できる。選択全体はRustのBTreeSetで保持し、wgpuで青く強調する。

輪郭パネルの点を選び、はさみアイコンで切断する。開輪郭の内部点では2本の開輪郭へ分割。閉輪郭では選択点を先頭にして開く。始点と終点が同じ位置に残るが、元の曲線や閉鎖辺は削除しない。切断点の滑らか連動を解除し、それ以外の設定を再配置する。線の途中で切る場合は、既存の中間点追加を行ってから切断する。

## ブール演算

輪郭一覧でチェックした閉輪郭群がA。パネル上部のBリストから、Aに含まれない別の閉輪郭を指定する。合成、A−B、共通部分、重なりの除外をアイコンで実行。Aは穴を含む複数輪郭を指定でき、全体を非ゼロ巻き数で解釈する。Bは単一輪郭、または設定した閉輪郭群。指定したAとBのみ置き換え、その他の輪郭は保持する。結果が空なら対象輪郭のみ削除される。

🟢 [Done] 初期実装の直線列出力は[曲線保持型ブール演算](curve-preserving-boolean.md)へ置き換えた。位相判定は0.001フォント単位の細分化、出力は元の二次・三次ベジェ区間を保持する。接続を確定できない場合は原形を保持して拒否し、直線列へのフォールバックは行わない。

| 制限 | 値 |
| --- | --- |
| A／B各側の輪郭数 | 1024まで |
| 細分化した入力の点数（A+B） | 8192まで |
| 再帰細分化 | 深さ24まで |
| 交差候補の検査 | 比較200万回、重なる辺の境界ボックス10万組まで |
| 出力点数 | 32768まで |
| 同時処理 | アプリ全体で1件 |

交差候補数を演算前に検査し、交差グラフの極端な増加を抑える。開輪郭、欠落インデックス、重複したA、Aと同じB、非有限座標や上限超過を拒否する。座標は従来の幾何検証範囲を使用する。入力・結果はRustワーカー内に保持し、WebViewへは設定・状態だけを送る。画素・全輪郭をIPCへ送らない。

## 履歴・保存・復旧

一括ドラッグ、数値移動、切断、ブール演算はそれぞれ1回のUndo。ドラッグキャンセルで元の文書を維持する。ブール演算はロック外のworkerで計算し、適用直前にepoch・glyph・revisionと編集中状態を再確認する。処理中に文書が変わればConflictとして破棄。成功時だけ対象グリフを原子的に置き換える。

確定した点・輪郭は既存のContour形式を使い、文書別の保存・自動保存・復旧へ接続する。スキーマ変更はない。点の選択やA/Bの選択は編集画面の一時状態として扱い、フォント出力・プロジェクトへは混入しない。点集合は文書のモデルごとに分離し、読込・構造変更・Undo/Redo時は既存の選択解除に合わせて整理する。

# 他アプリからのパス貼り付け

🟢 [Done] macOSの「編集 → ペースト」／⌘Vで、IllustratorとLumaPaintの選択パスを現在のグリフへ独立コピーする。コピー元アプリや元のパスへの参照は残さない。文字入力欄にフォーカスがある場合は、通常の文字列ペーストとして扱う。

## 操作

1. IllustratorまたはLumaPaintでベクターパスを選択し、コピーする。
2. Fontsで貼り付け先の文字を選び、キャンバスをクリックして⌘Vを押す。「編集 → ペースト」も使用できる。
3. 選択全体の縦横比を保ち、送り幅と上下端の90%以内へ中央配置する。複数パスの相対位置・変換を保持し、既存の輪郭へ追加する。
4. ノード・曲線ハンドルを編集する。1回のペーストを1回のUndo／Redoで戻せる。通常のプロジェクト保存と自動復旧の対象になる。

色・線幅・不透明度などの見た目はフォント輪郭へ持ち込まない。線は中心のパスを取り込むため、線幅を字形へ反映したい場合はコピー元で線をアウトライン化する。開いたパスも取り込めるが、フォント出力では閉じた輪郭を使用する。

## 形式と制限

- LumaPaint: `com.lumapaint.selection.v1`の`Vectors`。`path.data`・`fillRule`・アフィン変換を読み取り、SVG座標の下向きYをフォントの上向きYへ変換する。描画スタイルの追加フィールドと幾何形状を分離するため、現行版のregistration付き描画色にも対応する。LumaPaint側のソース変更や書き出し操作は不要。
- Illustrator: SVG、単一ページPDF、数値パス演算子に限定したAICBを順に試す。相対パス、二次・三次曲線、SVGの円弧、グループ変換、基本図形、単純なCSSクラスのfill／fill-ruleに対応する。PDFのForm XObjectと行列も読み取る。
- Illustratorで対応データが見つからない場合は、「環境設定 → クリップボードの処理」でPDFまたは「SVGコードを含める」を有効にしてコピーし直す。[Adobeのクリップボード設定](https://helpx.adobe.com/illustrator/desktop/manage-objects/edit-objects/copy-artwork-using-clipboard.html)。
- 複合パスの単純に入れ子になった偶奇の穴は、フォント用の逆向き輪郭へ変換する。交差する偶奇輪郭は変形せずエラーにする。
- テキスト、画像、クリッピングマスク、フィルター、LumaPaintのライブコーナー／角丸設定などの未展開オブジェクトは、事前のアウトライン化・展開・マスク解除を促す。SVGのuse、複雑なCSS、外部リソース、PDFのシェーディング、任意のPostScriptプログラムを実行・完全再現する機能ではない。
- 最大8MiB、合計65,536アンカー・セグメント、グリフ内4,096輪郭。偶奇の判定には追加の複雑度制限がある。PDFの解凍ストリームも16MiBに制限する。

## 所有と整合性

NSPasteboardはメインスレッドで読み、形式解析をworkerへ渡す。輪郭データはRustに保持し、WebViewはepoch・revision・glyphだけを送る。解析中に文書・グリフ・revisionが変わった場合、または未確定編集・試し組み・ファイル操作中の場合は確定しない。同時ペーストを直列化し、失敗時は輪郭・履歴を変更しない。

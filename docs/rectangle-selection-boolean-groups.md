# 矩形選択・両側の輪郭群によるブール演算（2026-11-04）

## 矩形選択

ノードツールで、点やハンドルに重ならないキャンバスの空白からドラッグする。矩形内と境界上のアンカーを選択する。Shiftを押して開始すると既存の選択へ追加。ドラッグの方向は自由で、ズーム・パンを反映したフォント座標で判定する。後続工程で制御点も選択対象へ追加した（[仕様](control-point-batch-editing.md)）。

枠と選択点はRust/wgpuで描画する。ドラッグ中も選択点が強調され、件数は確定後にUIへ反映される。マウスを離すと選択を確定し、選択済みアンカーのドラッグや数値入力で一括移動できる。Esc・ポインターキャンセル・ウインドウのフォーカス喪失では、開始前の選択へ戻る。空白をクリックするだけなら選択解除。Shift＋空白クリックは既存選択を保持する。

矩形選択自体は文書やUndo履歴を変更しない。選択後の移動は既存の1回のUndo/Redoへ接続する。選択途中は文書切替・画像・スニペット等の編集を拒否し、別のパネルからの割り込みを防ぐ。選択枠の状態はRust Modelのみが所有し、プロジェクトJSONへ混入しない。点の位置はRust側の輪郭から取得し、端点・制御点の選択集合をRustで保持する。

## B側の輪郭群

1. 輪郭一覧で、Bにしたい閉輪郭をチェックする。
2. パネル上部の「チェックした輪郭をBに設定」アイコンを押す。Bの件数が表示され、一覧のチェックは解除される。
3. 続けてAの閉輪郭をチェックし、合成・A−B・共通部分・重なりの除外を実行する。

A/B両側を非ゼロ巻き数で解釈するため、それぞれに穴を含む図形を指定できる。Bの件数にマウスを合わせると輪郭番号を確認できる。B群を設定している間は単一輪郭のドロップダウンを固定し、解除アイコンで単一輪郭指定に戻せる。Bは設定時のepoch・glyph・revisionに一致する間だけ有効で、別の文字や変更後の構造へ誤適用しない。

AとBの重複指定、欠落インデックス、開輪郭、重複したBインデックスは拒否。A/B各1024輪郭までとし、入力全体の細分化点数・交差計算量・出力点数には[従来の上限](multi-point-path-processing.md)を適用する。旧単一BのIPC要求は引き続き受け付ける。

演算はRust workerで行い、適用時に文書・文字・revision・編集中状態を再検査する。1回のUndo/Redoで戻せ、演算対象外の輪郭は保持する。確定した輪郭は既存の保存・復旧へ接続する。Bの指定と矩形選択は一時的な編集状態であり、プロジェクトへは保存しない。

🟢 [Done] 直線列出力は[曲線保持型ブール演算](curve-preserving-boolean.md)へ置換済み。既存のA／B輪郭群・非ゼロ巻き数と同じ経路を使用する。

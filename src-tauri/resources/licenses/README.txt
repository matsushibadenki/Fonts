Fonts MPL source availability

The unchanged .crate archives in sources/ contain the exact upstream Rust MPL-2.0 sources used by this lockfile. They are standard gzip-compressed tar archives and can be unpacked with tar -xzf. SHA-256 values are in license-inventory.json and match Cargo.lock.

These sources remain under MPL-2.0, not the Fonts MIT license. See MPL-2.0.txt. No MPL source files were modified.

lightningcss and its platform packages in package-lock.json are MPL-2.0 build dependencies, not included as executables in the Fonts app. If redistributing these development tools, separately provide the matching upstream sources and notices.
